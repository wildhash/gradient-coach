## How to Generate Your Own Examples

```bash
# Interactive mode
npm run dev

# Command line mode
npm run dev -- coach \
  --idea "Your project idea here" \
  --experience intermediate \
  --scaffold \
  --output ./my-output
```

## Understanding the Output

Each Gradient Coach run generates:
1. **gradient-coach-report.json** - Complete analysis in JSON format
2. **README.md** - Formatted markdown report
3. **cline-tasks.json** - Tasks ready for AI coding assistants
4. **scaffold/** - (Optional) Generated project files

## Tips for Best Results

1. **Be Specific**: Include key features and technologies you want to explore
2. **Be Realistic**: Consider your experience level honestly
3. **Use Constraints**: Add constraints if you have specific requirements
4. **Review Recommendations**: Even if marked feasible, read the concerns
5. **Iterate**: Adjust your idea based on the feedback and run again
