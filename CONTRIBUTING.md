# Contributing to Gradient Coach

Thank you for your interest in contributing to Gradient Coach! This tool is built to help the hackathon community ship faster.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/gradient-coach.git`
3. Install dependencies: `npm install`
4. Set up your API key: `export ANTHROPIC_API_KEY=your-key`
5. Run in development: `npm run dev`

## Development Workflow

```bash
# Make changes to src/ files
npm run build    # Compile TypeScript
npm run dev      # Test the CLI
npm run example  # Run the example script
```

## Code Style

- Use TypeScript for type safety
- Follow existing code patterns
- Keep functions focused and modular
- Add comments for complex logic

## Testing

Before submitting a PR:
1. Build the project: `npm run build`
2. Test the CLI: `npm run dev`
3. Run the example: `npm run example`

## Pull Request Process

1. Create a new branch: `git checkout -b feature/your-feature`
2. Make your changes
3. Build and test
4. Commit with clear messages
5. Push to your fork
6. Open a Pull Request

## Ideas for Contributions

- Add support for more tech stacks
- Improve feasibility validation logic
- Add templates for common hackathon projects
- Enhance the pitch generation
- Add export formats (PDF, slides, etc.)
- Integration with project management tools
- Support for team-based hackathons

## Philosophy

Gradient Coach is optimized for:
- **Speed**: Getting hackers started fast
- **Simplicity**: Minimal but effective recommendations
- **Realism**: Honest feasibility assessments
- **Action**: Concrete tasks, not just ideas

## Questions?

Open an issue or discussion. We're here to help hackers ship! 🚀
