# DigitalOcean Gradient AI Documentation

## Overview
Gradient AI is DigitalOcean's managed AI platform that provides access to leading LLM models through a simple API. It's compatible with the Anthropic SDK and OpenAI SDK, making integration seamless.

## Getting Started

### Authentication
```python
# Set your API key
export GRADIENT_AI_API_KEY="your-api-key-here"

# Or use Anthropic-compatible key
export ANTHROPIC_API_KEY="your-key-here"
```

### Base URL
- Production: `https://api.anthropic.com` (default)
- Custom endpoint: Set `GRADIENT_AI_BASE_URL` environment variable

## API Reference

### Making Requests
Gradient AI uses the Anthropic Messages API format:

```python
import httpx

async def call_gradient(prompt: str):
    async with httpx.AsyncClient() as client:
        response = await client.post(
            "https://api.anthropic.com/v1/messages",
            headers={
                "x-api-key": "your-api-key",
                "anthropic-version": "2023-06-01",
                "content-type": "application/json"
            },
            json={
                "model": "claude-3-5-sonnet-20241022",
                "max_tokens": 4096,
                "messages": [
                    {"role": "user", "content": prompt}
                ]
            }
        )
        return response.json()
```

### Available Models
- `claude-3-5-sonnet-20241022` - Most capable model (recommended)
- `claude-3-opus-20240229` - Previous generation
- `claude-3-sonnet-20240229` - Balanced performance
- `claude-3-haiku-20240307` - Fastest, most economical

For structured outputs:


Guide model behavior:

```python
{
    "model": "claude-3-5-sonnet-20241022",
    "max_tokens": 4096,
    "system": "You are an expert Python developer. Provide concise, working code.",
    "messages": [...]

```


## Best Practices

### Rate Limiting
- Respect rate limits (check response headers)
- Implement exponential backoff for retries
- Cache responses when possible

### Error Handling
```python
try:
    response = await client.post(...)
    response.raise_for_status()
except httpx.HTTPStatusError as e:
    if e.response.status_code == 429:
        # Rate limited, wait and retry
    elif e.response.status_code == 500:
        # Server error, retry with backoff
```

### Prompt Engineering
1. Be specific and clear
2. Provide examples when needed
3. Use system prompts for role/behavior
4. Request structured output formats
5. Include context and constraints

### Token Management
- Max tokens per request: 100,000 (input + output)
- Monitor token usage in responses
- Use appropriate max_tokens limits
- Consider model's context window

## Integration with FastAPI

### Async Endpoints
```python
from fastapi import FastAPI
from .gradient_client import GradientAIClient

app = FastAPI()
client = GradientAIClient()

@app.post("/api/generate")
async def generate(prompt: str):
    result = await client.generate_completion(prompt)
    return {"result": result}
```

### Streaming Responses
```python
from fastapi.responses import StreamingResponse

@app.post("/api/stream")
async def stream(prompt: str):
    async def generate():
        async for chunk in client.generate_streaming(prompt):
            yield chunk
    
    return StreamingResponse(generate(), media_type="text/plain")
```

## Performance Tips

1. **Batch Requests**: Group multiple prompts when possible
2. **Caching**: Cache common queries or responses
3. **Async/Await**: Always use async for I/O operations
4. **Connection Pooling**: Reuse HTTP clients
5. **Timeouts**: Set appropriate timeout values

## Security

1. Never expose API keys in client-side code
2. Use environment variables for credentials
3. Implement rate limiting on your API
4. Validate and sanitize user inputs
5. Log requests for monitoring (not the keys!)

## Troubleshooting

### Common Issues

**"Invalid API key"**
- Check environment variable is set
- Verify key format is correct
- Ensure no extra spaces in key

**"Rate limit exceeded"**
- Implement exponential backoff
- Consider request batching
- Upgrade to higher tier if needed

**"Context length exceeded"**
- Reduce input text length
- Lower max_tokens parameter
- Summarize long inputs first

**Timeout errors**
- Increase timeout value
- Check network connectivity
- Consider smaller requests
